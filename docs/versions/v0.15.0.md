# Version v0.15.0

This is the changelog for version 0.15.0.

## New

- **Watching data**: a `template.data` entry can set `watch: true` to reconcile the `ManagedResource` as soon as the referenced resource changes. It needs the updated CRD. See [watching data](https://kubensync.com/reference/template-data/#watching-data).

## Behavior changes

- The resources of a namespace are deleted as soon as it stops matching the `namespaceSelector` or is deleted, instead of on the next reconcile of the `ManagedResource`.
- Changes to data that is not watched are no longer picked up when a new namespace is created; use `watch: true` or force a reconcile by changing an annotation.
- The default memory limit is now 192Mi instead of 128Mi.

## Improvements

- Reconciles are much cheaper: a steady reconcile of 500 namespaces went from about 18,500 API requests to about 3,000.

## Upgrade notes

- On the first start, the operator deletes the resources of namespaces that stopped matching while the previous version was running.
- `watch: true` requires the updated CRD. If CRDs are not applied by the chart (`crd.enable: false`) or by your tooling, apply it manually; otherwise the field is silently dropped.
