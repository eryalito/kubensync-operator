# Version v0.14.0

This is the changelog for version 0.14.0.

## New

The Helm chart is now also distributed through a classic Helm Chart repo, in addition to the current OCI format:

```bash
helm repo add kubensync https://kubensync.com/charts
helm install kubensync kubensync/kubensync -n kubensync-system --create-namespace --wait
```

## What's Changed
* ci: publish charts to a classic Helm repo and drive releases from drafts by @eryalito in https://github.com/eryalito/kubensync-operator/pull/196
* docs: document installing from the classic Helm repository by @eryalito in https://github.com/eryalito/kubensync-operator/pull/197
